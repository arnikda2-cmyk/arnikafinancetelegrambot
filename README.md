# ربات تلگرام آرنیکا فایننس — نسخه تست

این نسخه یک نمونه اولیه قابل اجراست.

## تست
1. در BotFather یک Bot بساز و Token بگیر.
2. فایل `.env.example` را به `.env` تبدیل کن یا متغیر محیطی `TELEGRAM_BOT_TOKEN` را تنظیم کن.
3. نصب:
   pip install -r requirements.txt
4. اجرا:
   python bot/bot.py
5. داخل تلگرام برای ربات بنویس:
   طلای ۱۸

ربات در این نسخه یک پوستر ۱۲ کادری آزمایشی تحویل می‌دهد.

## مرحله بعد
- جایگزینی قالب آزمایشی با ۱۲ اسلاید نهایی واقعی آرنیکا
- اتصال به داده کندلی واقعی
- موتور P/H/L/F/R/K
- شمارش گن
- اهداف کوتاه‌مدت و میان‌مدت
- تولید خودکار تحلیل
- دکمه «تأیید انتشار»
- انتشار در کانال پس از تأیید
